# Polendina Downloads

**By Nicola Cavina · Powered by GePpeTto**

Polendina is a plugin catalog and FX panel for REAPER on Windows x64.

[Download the beta](https://github.com/darnede/Polendina-Downloads/releases)

Open the release and download **Polendina.exe** under **Assets**. English and Italian guides are available on the same page. Put the executable in a writable folder and double-click it. If you are updating, keep your existing `data` folder.
