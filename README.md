# Polendina Downloads

**By Nicola Cavina · Powered by GePpeTto**

Polendina is a plugin catalog and FX panel for REAPER on Windows x64. The full app also reads saved REAPER projects and provides experimental Samplitude VIP plugin inventory.

[Download Polendina 0.7.0 Beta 3](https://github.com/darnede/Polendina-Downloads/releases/tag/v0.7.0-beta.3)

Under **Assets**, choose **Polendina-2026-11-18.exe** for the current build, including the Panel's Unassigned manufacturer label. Put it in a writable folder and double-click it. When updating, close Polendina, replace the executable, and keep your existing `data` folder. English and Italian guides are attached to the release.

After updating, use **Window in REAPER** to replace your installed **Polendina_Panel.lua**, then restart its REAPER action. The table supports sorting and dragging column headings.
